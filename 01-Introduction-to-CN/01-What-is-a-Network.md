# What is a Network?

A **computer network** is a collection of interconnected devices that communicate with each other to exchange data and share resources.

## Why Do We Need Networks?

Networks allow devices to:

- Exchange data and information
- Share resources such as files, printers, and applications
- Communicate with each other
- Access services such as the Internet
- Improve resource utilization

## Components of a Network

A basic network consists of:

- **Sender** – Device that sends data
- **Receiver** – Device that receives data
- **Transmission Medium** – Path through which data travels
- **Network Devices** – Devices such as switches, routers, and access points
- **Protocols** – Rules that define how devices communicate

## Types of Connections

### Wired

Uses physical transmission media such as:

- Ethernet cables
- Fiber-optic cables

### Wireless

Uses wireless signals such as:

- Wi-Fi
- Bluetooth
- Cellular networks

## Example

When multiple computers are connected through a switch and
communicate with each other, they form a computer network.

The Internet is an example of a **large-scale computer network**
that connects networks around the world.

## Important Terms

- **Node:** Any device connected to a network.
- **Link:** The communication path between two nodes.
- **Protocol:** A set of rules used for communication.
- **Bandwidth:** The maximum data-carrying capacity of a network connection.
- **Packet:** A small unit of data transmitted over a network.

## Interview Answer

**Q: What is a computer network?**

**Answer:**

A computer network is a collection of interconnected devices
that communicate with each other using predefined protocols
to exchange data and share resources.
